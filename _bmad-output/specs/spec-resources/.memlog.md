## v1.1 revision — 2026-10-27

- (decision) `resource_type` expanded to PROJECTOR, KIT, COMPUTER, NOTEBOOK, AUDIO_VISUAL, CAMERA, MICROPHONE, DISPLAY, CABLE, ADAPTER, OTHER. Type stays descriptive; `active` remains the only gate.
- (decision) `occurrence_status` gains `IN_PROGRESS` with `started_at`; legal transitions `OPEN → IN_PROGRESS`, `OPEN → RESOLVED` (shortcut), `IN_PROGRESS → RESOLVED`; `RESOLVED` remains terminal. Dataset-wide `CANCELLED` was considered and rejected for v1.
- (decision) OQ-R1 answered: occurrences carry `reported_by` (create, from JWT employeeId), `assigned_to` (START, request value or caller), `resolved_by` (RESOLVE, from JWT). No cross-context FK to employees.
- (change) Occurrence PATCH is action-based (`OccurrenceAction` = START | RESOLVE); `status` is never client-supplied. New 409 reason `OCCURRENCE_ALREADY_IN_PROGRESS`; new 403 reason `EMPLOYEE_IDENTITY_REQUIRED`.
- (change) BFF adds `inProgressOccurrenceCount`; `openOccurrenceCount` keeps counting only OPEN.
- (validation) schema.sql applied to a disposable PostgreSQL and guards exercised; both contracts pass the OAS 3.1 meta-schema.

## v1.2 revision — 2026-10-28

- (decision) `resource_type` has no `OTHER` fallback and no `AUDIO_VISUAL`; `KIT` renamed to `HEALTH_KIT`. Final set: PROJECTOR, HEALTH_KIT, COMPUTER, NOTEBOOK, CAMERA, MICROPHONE, DISPLAY, CABLE, ADAPTER. An unlisted kind of stock requires an enum migration.

- (decision) Timestamps stay `TIMESTAMP WITH TIME ZONE`; `Date` in the conceptual model is display shorthand, not a date-only column.

## v1.3 revision — 2026-10-28

- (change) Occurrence PATCH is resolve-only (`{resolution}`); `OccurrenceAction`/`OccurrenceStart` are gone. 409 reason `OCCURRENCE_ALREADY_IN_PROGRESS` removed. BFF loses `inProgressOccurrenceCount`.
- (decision) Audit actors are `reportedBy` (create) and `resolvedBy` (resolve).

- (validation) PostgreSQL rejects status 'IN_PROGRESS'; only OPEN -> RESOLVED is accepted; both contracts pass the OAS 3.1 meta-schema.
